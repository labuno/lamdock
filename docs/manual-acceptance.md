# 当前手工验收清单

状态：以下场景均待真实环境验证。自动测试通过不代表这些场景已验收。
本清单承接旧 Phase 1、ChatGPT 重启、Antigravity 端口计划和当前发布计划的有效验收项；
旧任务编号、退役的整帐号 Sync 和本地 Usage 不再作为执行要求。

## 环境与记录

先运行 `make check`，使用本轮构建的 `LamDock.app`；版本与哈希见
[发布执行记录](release-cleanup-execution-report.md)。

现有旧 LAM 与本项目保留相同应用标识和默认目录。先以独立 `LAM_HOME` 验证启动；
真实帐号验收另行安排，避免两个实例同时读写同一数据。测试会话删除、帐号删除和
ChatGPT 重启时使用可处置的测试帐号/会话，并先保存正在进行的工作。

每次验收记录 macOS / Codex CLI / 应用版本、所用 Provider 协议、场景、实际结果和日期。
