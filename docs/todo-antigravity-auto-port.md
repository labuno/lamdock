# Antigravity 自动识别监听端口

- 状态：验证成功
- 输入：运行中的 Antigravity 语言服务进程；可选手动端口。
- 输出：默认从该进程的 TCP 监听端口查询额度，重启后重新发现；不要求用户查询或复制端口。
- 约束：只发现已识别进程的端口，复用现有额度查询与并发控制；手动值明确覆盖自动发现；未运行时提示打开 Antigravity。
- 测试先行：解析 IPv4/IPv6、去重/无效输入、真实进程随机监听端口、手动覆盖绕过发现、缓存匹配；前端默认自动加载、刷新去重、配置变化取消旧响应、设置提示。
- 验证：聚焦前后端测试、相关回归、Clippy/fmt/build、真实本机进程发现（不输出令牌），打包启动。
